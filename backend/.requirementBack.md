Create a lightweight backend using Node.js and Express for a Cyber Awareness project. The purpose of this backend is to handle form submissions from the frontend ('Having Problem' page) where users describe a cyber incident they faced.

When the form is submitted, the backend should:

Accept POST requests at /api/report that include data like:

name (optional)

email

incidentTime

location

description (required – full detail of the incident)

Use this description to create a prompt and send it to the Gemini API. The prompt should ask Gemini to:

Analyze the situation.

List the most likely applicable Indian cyber laws (sections).

Explain those laws in simple terms.

Suggest where and how the user can file a complaint (website link, cyber cell, helpline, etc).

Return the response from Gemini as a JSON object to the frontend, along with a success message.

Setup includes:

Use express.json() for parsing JSON.

Use cors to allow requests from the frontend.

Store the Gemini API key securely using dotenv.

Create a routes/report.js route handler to manage the /api/report POST logic.

All logic that communicates with the Gemini API should be modularized into a helper file like utils/geminiClient.js.

Don't include any database or data storage for now. Just receive the form, process it, and respond.

Suggested Backend File Structure (No Database):
backend/
├── routes/
│   └── report.js          // Route for handling POST /api/report
├── utils/
│   └── geminiClient.js    // Helper to talk to Gemini API
├── server.js              // Main Express server setup
├── .env                   // Gemini API Key goes here
├── package.json
└── README.md


Want to simulate storage later? You can store reports in an array for now.

Add basic form validation to avoid empty submissions

Example Gemini Prompt (to be sent via API)
A user has reported the following cyber incident:

---
Incident Description:
"I received an email claiming to be from my bank, asking me to verify my account information. I clicked the link, entered my bank credentials, and now my account is showing unauthorized transactions."
Time of Incident: 7th April 2025, around 3 PM  
Location: Delhi, India
---

Based on this incident, please answer the following:

1. What are the possible Indian cyber laws or IPC sections that may apply to this case?
2. Provide a **simple explanation** of each relevant section.
3. Suggest **where and how** the person can **file a complaint**, such as:
   - Official websites
   - Cyber cell links
   - Helpline numbers
   - Required documents

Keep your tone informative but simple enough for a non-technical user to understand. Avoid legal jargon if possible. Respond in a clear bullet-point or paragraph format.
